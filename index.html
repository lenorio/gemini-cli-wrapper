Local Gemini CLI
with Zero API Keys

Управляйте Google Gemini прямо из терминала. Полная история диалогов, планирование изменений, парсинг сайтов и отправка медиафайлов через Playwright сессии — без токенов, ключей и платных подписок.

git clone https://github.com/lenorio/gemini-cli-wrapper.git && cd gemini-cli-wrapper && install.bat
