Этот инструмент запускает официальный интерфейс Google Gemini прямо в вашем терминале и параллельно поднимает локальный API-сервер. Все работает через автоматизацию браузера Playwright на базе gemini.google.com. Вам не нужны официальные ключи API, платные подписки или лимиты.

---

## Возможности

Что умеет проект:

- Интерактивный TUI. Удобная консоль для общения, вдохновленная интерфейсом Claude Code. Достаточно запустить gemini-cli и писать промпты.
- Вход без токенов. Вы один раз авторизуетесь в Google аккаунте через открывшееся окно браузера, и сессия сохраняется локально. Все последующие запуски работают бесшумно в фоновом режиме.
- Быстрое переключение моделей. Смена моделей (3.5 Flash, 3.1 Pro, 3.1 Flash-Lite) прямо в процессе диалога через меню.
- Режим глубокого мышления. Включение и выключение Extended reasoning на лету.
- Работа через Socks5 прокси с авторизацией. Chromium из коробки не умеет работать с Socks5 прокси, требующими логин и пароль. Мы решили эту проблему, встроив локальный HTTP-to-SOCKS5 мост. Трафик безопасно идет через локальный сервер-посредник.
- Автоматический парсинг веб-страниц. Если вставить ссылку в промпт, скрипт сам скачает страницу, очистит ее от разметки и рекламы, а затем передаст Gemini в качестве контекста.
- Загрузка файлов и картинок. Прикрепление локальных файлов и медиа по путям, указанным прямо в тексте запроса.
- Режим планирования. Gemini сначала сгенерирует пошаговый план реализации и спросит подтверждение перед тем, как выдавать готовый код.
- История и управление диалогами. Выбор прошлых сессий стрелочками, быстрые переходы по ID, переименование чатов и экспорт истории в Markdown.

## Установка за один шаг

Выберите команду для вашей операционной системы, чтобы автоматически установить зависимости npm, скачать Chromium для Playwright и связать команду gemini-cli глобально в системе.

### Windows (CMD)
Запустите файл install.bat или выполните:
```cmd
install.bat
```

### Windows (PowerShell)
```powershell
.\install.ps1
```

### macOS / Linux
```bash
chmod +x install.sh && ./install.sh
```

## Первый запуск и авторизация

Перед использованием нужно один раз войти в Google аккаунт, чтобы CLI запомнил сессию:
```bash
gemini-cli login
```
1. Откроется окно браузера Chrome или Edge.
2. Войдите в свой профиль Google (поддерживается двухфакторная аутентификация и ключи безопасности).
3. Как только загрузится интерфейс Gemini, консоль сохранит сессию и окно закроется автоматически. Все данные хранятся локально в папке ~/.gemini-cli-session.
4. Больше входить не потребуется. Все будущие запросы будут выполняться скрытно в фоне.

## Работа в интерактивном чате

Чтобы запустить интерактивный терминал, выполните:
```bash
gemini-cli
```

### Список доступных слэш-команд

| Команда | Действие |
|:---|:---|
| /help или ? | Показать список команд |
| /model | Выбрать модель стрелочками (Flash, Pro, Flash-Lite) |
| /thinking | Выбрать режим размышления стрелочками (Standard / Extended) |
| /formatting | Выбрать формат вывода стрелочками (CLI, Telegram, HTML) |
| /proxy | Настроить прокси или сбросить настройки (/proxy clear) |
| /reset | Начать новый чат с чистого листа |
| /plan | Включить или выключить режим подтверждения планов |
| /link | Получить ссылку на текущий диалог в веб-интерфейсе |
| /conversations | Открыть список прошлых диалогов и переключиться стрелочками |
| /goto [id/name] | Перейти в конкретный диалог по названию или ID |
| /rename [id] [name] | Переименовать чат в базе |
| /add-agent [path] | Загрузить системные инструкции из Markdown-файла |
| /compact | Сжать историю общения в краткое резюме для экономии токенов |
| /savememory | Сохранить всю историю текущего чата в md-файл |
| /settings | Интерактивная панель настроек (API порт, модель по умолчанию, статус API сервера) |
| /clear | Очистить консоль |
| /exit или /quit | Закрыть браузер и выйти из сессии |

## Локальный REST API

Проект автоматически запускает Express сервер на порту 8000 (если он включен в настройках). Это позволяет обращаться к активной сессии Gemini из внешних скриптов.

- **Адрес**: POST http://localhost:8000/ask
- **Метод**: POST
- **Параметры запроса (JSON)**:
  - prompt (строка, обязательно): Текст запроса.
  - model (строка, опционально): Выбор модели.
  - thinking (строка, опционально): Режим размышления.
  - formatting (строка, опционально): Формат вывода.

Подробное описание работы API, структуры ответов и примеры для cURL, PowerShell, Python и Node.js находятся в файле [API_DOCS_RU.md](API_DOCS_RU.md).

## Безопасность

Профиль браузера хранится локально на вашем компьютере:
- Windows: C:\Users\<ИмяПользователя>\.gemini-cli-session
- Mac/Linux: ~/.gemini-cli-session

Данные сессии никуда не отправляются и используются только для взаимодействия с официальным сайтом gemini.google.com.
